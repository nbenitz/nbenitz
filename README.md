## Selected projects

### [Granja Luna Agent](https://github.com/nbenitz/granja-luna-agent)

A human-in-the-loop agentic system for poultry-farm operations. It turns natural-language input into reviewable structured drafts, applies risk rules and keeps an auditable event history before operational data is confirmed.

**Stack:** Python, FastAPI, React Native, Expo, TypeScript, JSON Schema, Playwright and Docker.

The repository also documents [how I use OpenAI Codex](https://github.com/nbenitz/granja-luna-agent/pull/2) for analysis, planning, initial implementation, refactoring and testing while retaining human review and responsibility for business rules.

### [Avícola MBoré](https://github.com/nbenitz/avicola-mbore)

A full-stack management application for poultry operations, including purchases, sales, inventory, health records, incubation, sensors and farm-layout planning.

**Stack:** React, TypeScript, Vite, FastAPI, PostgreSQL/SQLModel, Docker and automated tests.
